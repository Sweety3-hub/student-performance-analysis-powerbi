# Student Performance Analysis

## Project Overview

This project analyzes student performance data using Python and Power BI.

The project focuses on exploring student academic performance, identifying patterns in the data, and presenting the analysis through an interactive Power BI dashboard.

## Objective

The main objectives of this project are:

* Analyze student performance data
* Explore factors related to academic performance
* Prepare and analyze the dataset using Python
* Create meaningful metrics and visualizations
* Build an interactive Power BI dashboard
* Identify useful patterns and insights from student data

## Tools & Technologies

* **Python**
* **Pandas**
* **Power BI**
* **DAX**
* **Power Query**
* **CSV Dataset**

## Dataset

The project uses a student performance dataset containing information related to student academic and personal characteristics.

The dataset is stored in:

```text
student_performance.csv
```

## Data Analysis with Python

Python was used for initial data analysis and exploration.

The Python analysis is available in:

```text
analysis.py
```

Python and Pandas were used to work with the dataset and explore the available information before creating the Power BI dashboard.

## Power BI Dashboard

The analyzed data was used to create an interactive Power BI dashboard.

The Power BI project file is:

```text
data analysis project(students).pbix
```

The dashboard allows the data to be explored through visualizations and interactive filtering.
